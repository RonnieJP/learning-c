# Learning the C Programming Language

As a mathematics student, these are my first steps to break into software engineering. I have programmed in the past with languages such as Python, JS and R, but wanted to learn something closer to the machine.

## Resources

### Main

- [Modern C - Jens Gustedt](https://gustedt.gitlabpages.inria.fr/modern-c/)
  - Main textbook.
  - Work through the material and exercises.
  - Use the compiler and experiments alongside it.

### Secondary

- The C Programming Language - Kernighan & Ritchie.
  - Classic C text.
  - Useful for exercises and alternative explanations.
  - Written for C89/C90, for not used as the modern language reference.

### Reference

- [cppreference - C](https://en.cppreference.com/w/c)
  - C language and standard library reference.
  - Use when I need to look up how something works rather than learn it from scratch.

- `man`
  - Use the system documentation for C/POSIX functions.
  - Examples: `man malloc`, `man printf`

## Approach

I want to learn C primarily without relying on LLMs.

### Preferred order when stuck

1. Think about the problem myself.
2. Read the relevant section of the book.
3. Check documentation / `man` pages.
4. Experiment with a smaller program.
5. Read compiler warnings and errors.
6. Search the web / existing source code.
7. Ask someone or use an LLM as a last resort.

The goal is not to avoid help completely. The goal is to develop the ability to investigate and solve problems independently.
